# Semana 1: Portafolio web

## Objetivo

Crear y personalizar un portafolio web utilizando GitHub Pages, Jekyll y Just the Docs, con el propósito de contar con un espacio para organizar mis prácticas, documentos, proyectos y evidencias realizadas durante el curso.

## Desarrollo

Durante esta primera semana se realizó la configuración y personalización inicial del portafolio web.

Primero se revisó la estructura del repositorio para identificar los archivos necesarios para el funcionamiento de la página. Posteriormente, se modificó el contenido principal utilizando archivos Markdown (`.md`).

También se creó una autobiografía como parte del contenido inicial del portafolio y se modificó el diseño de la página mediante el archivo `custom.css`.

Entre los principales cambios realizados se encuentran:

- Modificación del contenido de la página principal.
- Creación de una autobiografía.
- Organización del repositorio.
- Eliminación de contenido innecesario de la plantilla.
- Personalización del menú lateral.
- Cambio de la paleta de colores original por una escala de grises.
- Modificación del nombre del portafolio.
- Publicación y actualización del sitio mediante GitHub Pages.
